# Промышленность: прогнозирование температуры сплава

Регрессия температуры выплавляемого сплава по данным технологического процесса. Заказчик — металлургический комбинат; требование по MAE — не выше 6.8 °C.

## Данные

SQLite-база `ds-plus-final.db`, 7 таблиц:

| Таблица | Содержимое |
|---|---|
| `data_arc` | параметры электродуговой печи, `active_power`, `reactive_power` |
| `data_bulk`, `data_bulk_time` | сыпучие материалы и время их загрузки |
| `data_gas` | подача газов |
| `data_temp` | замеры температуры |
| `data_wire`, `data_wire_time` | подача проволоки |

Таблицы объединяются по `key` — идентификатору плавки. База в репозиторий не входит.

## Подход

- EDA: распределения, выбросы, phik-корреляции для смешанных типов признаков.
- Объединение 7 таблиц в одну плоскую; агрегация временных таблиц по плавке.
- Отбор признаков, устранение утечек (признаки, измеренные после выпуска плавки, исключены).
- Сравнение `DummyRegressor`, `DecisionTree`, `RandomForest`, `LGBM`, `CatBoost`, `MLP`, `RidgeCV`, `ExtraTrees`, `HistGradientBoosting`, `StackingRegressor`.
- `TransformedTargetRegressor` + `RobustScaler`/`QuantileTransformer`, подбор гиперпараметров через `RandomizedSearchCV`.

## Результат

| Метрика | Значение |
|---|---|
| **MAE на тесте** | **5.99 °C** |
| R² | 0.49 |
| Требование заказчика | ≤ 6.8 °C ✅ |

Модель заметно лучше константного прогноза; R² 0.49 отражает высокую долю технологического шума в процессе.
